# Erdős #1038 Agent Work Staging Lane

Status: `PUBLIC_SAFE_AGENT_STAGING`

This directory is a public-safe staging lane for external agent work on Erdős
#1038. It exists so browser-based agents such as Perplexity Computer can inspect
the current public context through a public GitHub repository instead of needing
private-repo access.

This lane is not a proof, not a publication, and not a status upgrade.

## Rules

- Treat all content here as `INTENT_ONLY` until locally assimilated into a
  checked packet.
- Do not claim Erdős #1038 is solved.
- Do not claim public SOTA improvement.
- Do not claim altitude, KKT, Lean, coefficient-box, period-legitimacy,
  attainment, selector-existence, or global-reduction closure from this folder.
- Do not add credentials, tokens, local filesystem paths, private Linear links,
  private Git URLs, protected scoring internals, or unpublished atlas internals.
- Return proposed work as patches, theorem scaffolds, algorithms, or packet
  drafts; do not mutate the authoritative private working route.

## Public Agent Modes

Mode 1: `MODE_1_REVIEW_RESEARCH_OPINE`

Use for public-paper research, route critique, hidden-hypothesis detection,
orthogonal attack ideas, and next-gate recommendations.

Mode 2: `MODE_2_INTENSE_SOLVE`

Use for concrete work product on one blocker: proof scaffolds, patch proposals,
Rust/Python/Lean skeletons, verification commands, or packet drafts. Mode 2
work remains `WORK_PRODUCT_INTENT_ONLY` until a local agent verifies and imports
it.

## Current Public Work Surface

- `CURRENT_FRONTIER.md` gives the sanitized route frontier.
- `EVEREST_ROUTE_FRAME.md` defines the altitude / Route Confound / next ridge
  analogy used by this project.
- `MODE2_GIT_HANDOFF.md` gives the Perplexity Computer handoff.
- `PUBLIC_CONTEXT.json` gives a machine-readable public context object.
- `WORK_QUEUE.jsonl` lists current public-safe tasks.

The private working archive may contain newer packet artifacts. If a later
public handoff or local assimilation packet supersedes this folder, stop and ask
for a refreshed context rather than solving from stale state.
