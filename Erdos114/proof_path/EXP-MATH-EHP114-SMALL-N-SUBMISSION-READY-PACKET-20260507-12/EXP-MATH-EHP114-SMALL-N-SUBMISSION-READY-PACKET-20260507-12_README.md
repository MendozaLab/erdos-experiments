## Finite theorem

For every monic complex polynomial `p` of degree `n` with `1 <= n < 15`, the lemniscate length `L({|p|=1})` is at most the lemniscate length of `p(z) = z^n - 1`.

## n=13 route note (read before posting publicly)

The `n=13` row in the underlying experiment artifact `EXP-MM-EHP-007-n13-inari_RESULTS.json` reports `bb_total_evals = 0` and `bb_level_count = 0`, while neighboring rows (`n=12`: 45M, `n=14`: 855M) are populated. The interval bounds `L*_lower = 28.85923995588822`, `L*_upper = 28.859239955888235` are present, but the branch-and-bound search structure is empty.

Two interpretations are consistent with the artifact:

1. The row was generated by a different evaluator pass than `n != 13` and the underlying interval bounds were obtained directly without iterative refinement.
2. The row is an artifact-of-tooling and should be re-run before any third-party citation.

**Recommendation for this packet:** quarantine `n = 13` from the public reviewer-grade table until it is re-run with the same evaluator profile as `n = 12, 14`. The packet status `finite_theorem_ready` is set conditional on this re-run.

The `n = 13` artifact remains in the Zenodo record (10.5281/zenodo.19480329) for transparency; the public submission text covers `1 <= n <= 12` and `n = 14`, with `n = 13` listed as "pending route reconciliation."
