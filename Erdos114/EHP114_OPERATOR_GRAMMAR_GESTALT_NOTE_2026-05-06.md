## Purpose

This note records a mental model that helps keep the research architecture
sharp without promoting the model to evidence. The point is not that three
operators exhaust mathematics. The point is that three operators recur across
the proof architecture often enough to be useful as a reading grammar:

```text
ratio       = invariant / normalization
square      = error / energy / dimension ledger
square root = observable / fluctuation scale
```

The rest is not bookkeeping. The rest is structure, regularity, and limits.
Those are exactly where proofs live.

## Orthodox Version

Ratios remove units and expose comparisons. They are how a local object becomes
dimensionless enough to be compared across scales.

Squares turn signed deviations into a ledger. They make error positive, let
independent directions add, and make dimension visible as the number of squared
channels being paid for. In finite-dimensional geometry this is Pythagoras. In
Hilbert space it becomes an integral squared norm.

Square roots report back in observable units. They convert squared energy,
variance, or error into length, amplitude, or fluctuation scale.

This grammar is useful because it stops the same structure from looking
unrelated in different subjects. It does not replace the subject-specific
theorem.
